# diegoporfirio.github.io

Site oficial do desenvolvedor **Diego Porfirio**, publicado com GitHub Pages.

🔗 https://diegoporfirio.github.io

## Aplicativos

**WidgetBTC: Preço do Bitcoin** — widget de tela inicial para Android que mostra a cotação do Bitcoin atualizada, sem precisar abrir o app.

## Conteúdo deste repositório

| Arquivo | Para que serve |
|---|---|
| `index.html` | Página inicial com informações do app e contato |
| `privacidade.html` | Política de privacidade exigida pelo Google Play e AdMob |
| `app-ads.txt` | Verificação de propriedade do inventário no AdMob (IAB Tech Lab) |
| `.nojekyll` | Desativa o Jekyll para servir os arquivos como estão |
